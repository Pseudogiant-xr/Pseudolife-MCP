### Changed (2026-11-24 — the native installers read the release version from the native client crate)
- `ops/install-native.sh` and `ops/install-native.ps1` now read the release version of the archive they fetch from the `version` in the `[package]` table of the checkout's `rust/shim/Cargo.toml`, no longer from `pyproject.toml`. A checkout whose crate names no version is refused with a message that names that file. This is the same field `rust/ci/release_version.py` and the native client read, so the installers keep working once the Python package and its `pyproject.toml` are gone.
