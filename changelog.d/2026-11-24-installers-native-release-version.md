### Changed (2026-11-24 — the native installers read the release version from the native client crate)
- `ops/install-native.sh` and `ops/install-native.ps1` now read the release version of the archive they fetch from the `version` in the `[package]` table of the checkout's `rust/shim/Cargo.toml`, no longer from `pyproject.toml`. A checkout whose crate names no version is refused with a message that names that file. The reader is table-aware and case-sensitive. It accepts a one-line basic or literal string and ignores a leading byte-order mark, as `rust/ci/release_version.py` does. With #1927, which moves the native client's checkout mode to the same field, a native install no longer reads `pyproject.toml`.
- `ops/integrate.py` run from a controller checkout that lacks `rust/ci/release_version.py` now refuses with a message telling you to update the controller checkout, instead of failing with a bare `FileNotFoundError` when it classifies a release cut.
