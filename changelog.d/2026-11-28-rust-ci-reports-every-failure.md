### Changed (2026-11-28 — one red Rust CI run reports every lint and test failure)
- The `Rust / <os>` jobs in `rust.yml` keep running their checks after a lint fails. A Clippy or format failure used to skip Nextest, and Nextest stopped at its first failing test. Now the compile checks, Clippy, the PDFium provision and both Nextest passes run whenever every earlier step (the Python checks included) and the compile check they need succeeded, and Nextest uses a new `ci` profile in `rust/.config/nextest.toml` that does not fail fast. The job still fails when any of these steps fails. The goldens replay, the Windows DLL import check and the override builds are still skipped after a failure.
- Agent behaviour that changes: when a run fails, an agent reruns the failing step or slice with fail-fast off on the platform that failed and fixes the whole list in one round. A change merged without hosted CI, from a private fork, first runs every hosted job's commands on the dev machines for each platform it touches; macOS has no dev machine, so the change notes that macOS is untested before merge.
