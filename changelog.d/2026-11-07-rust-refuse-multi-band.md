### Changed (2026-11-07 — Rust daemon refuses retired multi-band layouts at startup)
- Multi-band memory presets (`continuum`, `titans`, `moneta`, `yaad`, `memora` and a `custom` list of more than one band) and every band `retention_policy` other than `balanced` were retired from both engines on 2026-11-02. The Rust daemon now refuses to start on them with an error that names the setting and the fix: flatten the bank and config with `pseudolife-mcp migrate-flat`, which backs up and keeps every entry, or keep the Python engine until then. Flat and single-band `balanced` configurations start as before. This is the Rust half of the retirement; the Python half lands separately.
