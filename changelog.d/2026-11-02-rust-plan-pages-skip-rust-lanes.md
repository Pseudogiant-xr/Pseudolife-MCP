### Changed (2026-11-02 — editing the Rust cutover plan no longer runs the whole Rust test matrix)
- A pull request or batch that changes only `rust/CUTOVER.md`, `rust/DEV.md` or `rust/SEMANTICS-CHECKLIST.md` (and other documentation) now counts as documentation-only in the Rust workflow, so it skips the Rust, candidate and parity jobs, as a change to `docs/` already did. Before, any Markdown file under `rust/` ran the full matrix on both operating systems: a two-row recount in the cutover plan queued 16 parity and Rust jobs. A page a job reads (`rust/PARITY.md`, `rust/PORTING.md`) or one an evidence file hashes still runs everything, and a new test fails if any code outside the Python suite starts reading one of the listed pages. The master push that merges such a batch still runs the Rust job.
