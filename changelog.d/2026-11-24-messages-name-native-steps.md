### Fixed (2026-11-24 — messages name steps an installed client has) [#1609]
- The native client's version-mismatch notes (shim stderr, served instructions, `doctor`) no longer add a checkout-only `python ops/update_clients.py` step; `pseudolife-mcp update --clients-only --tag <version>` is the step.
- `doctor` no longer tells a native client to run `-m pip check` on a Python interpreter when its own stdio shim cannot start or finish the MCP handshake; it points at daemon health, the shim's stderr and `pseudolife-mcp update --clients-only --reinstall --tag <version>`.
- `connect` gives the native installer run that registers Claude Desktop (`PSEUDOLIFE_SHIM_ENGINE=native`, `--client claude-desktop`, and the daemon URL and token file for a remote daemon) instead of `python ops/register_claude_desktop.py`, and `pseudolife-mcp update --clients-only` instead of `python ops/shim_runtime.py migrate`.
- `import` of an export with other embedding dimensions no longer names `ops/migrate_embeddings.py`; it says this client does not re-embed and which exports the bank takes.
- `pseudolife-mcp --help`, `ops/install-hook-native.sh --client codex --remove-legacy` and the plugin README name the native installer and `update` instead of checkout Python scripts.
- `pseudolife-mcp --help`'s `tunnel` line lists what the native tunnel does: save or resume a profile and import or renew its runtime key, show status, verify cloud access, run in this terminal and stop. It no longer lists guided setup, `doctor` or opted-in autostart, which the native client refuses.
