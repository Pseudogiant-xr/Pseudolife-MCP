### Fixed (2026-11-06 — The native client runtime finds its digest and lease locks where the hooks and Python look)
- On Windows the native (Rust) client runtime located its board digest (`~/.pseudolife-mcp/digests`) and lease locks (`~/.pseudolife-mcp/locks`) through the OS profile folder and ignored `USERPROFILE`. The plugin hooks, the Python runtime and the rest of the native CLI honour `USERPROFILE`, so whenever it pointed elsewhere the native shim wrote its digest where the hooks never looked: no prompt-hook mail note, park gate, Stop-hook wake or `wait-mail` for that session, and lease locks outside the lock directory everything else uses.
- Both now use the home Python's `Path.home()` names: `USERPROFILE` (else `HOMEDRIVE` + `HOMEPATH`) on Windows and `HOME` elsewhere, falling back to the OS profile only when none is set. `PSEUDOLIFE_DIGEST_DIR`, `PSEUDOLIFE_AGENT_STATE_DIR`, `CODEX_HOME` and `PSEUDOLIFE_LEASE_LOCK_DIR` still take precedence.
