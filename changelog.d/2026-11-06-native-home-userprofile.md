### Fixed (2026-11-06 — The native client runtime finds its digest and lease locks where the hooks and Python look)
- On Windows the native (Rust) client runtime located its board digest (`~/.pseudolife-mcp/digests`), its lease locks (`~/.pseudolife-mcp/locks`) and its default Codex agent state (`~/.codex/pseudolife/agents`) through the OS profile folder and ignored `USERPROFILE`. The plugin hooks and the Python runtime honour `USERPROFILE`, so whenever it pointed elsewhere the native shim wrote its digest where the hooks never looked. That session then got no prompt-hook mail note, park gate, Stop-hook wake or `wait-mail`, and its lease locks landed outside the lock directory everything else uses.
- The board, `wait-mail`, the lease lock directory and `board-audit stats` now resolve home as Python's `Path.home()` does: `USERPROFILE` (else `HOMEDRIVE` + `HOMEPATH`) on Windows, and `HOME` on Linux and macOS, where an empty `HOME` means `/`. They fall back to the OS profile only when none is set. `PSEUDOLIFE_DIGEST_DIR`, `PSEUDOLIFE_AGENT_STATE_DIR`, `CODEX_HOME` (now ignored when empty, as Python and the hooks do) and `PSEUDOLIFE_LEASE_LOCK_DIR` still take precedence.
