### Deprecated (2026-11-07 — the five retired Console routes answer 501 on the Rust daemon)
- The five Console REST routes deprecated in 0.21.0 stay deprecated, and the Python daemon still serves them. A daemon running the Rust engine (today only through checkout-mode `pseudolife-mcp update --engine rust`) answers each with `501 not_implemented`, so a script that calls one must move before it runs against that engine: `POST /api/lessons/restore` and `POST /api/world/restore` become `memory_graph_review(action="restore_slot")` with `store="lesson"` or `store="world"`; `GET /api/curation/retired`, `GET /api/graph/communities` and `GET /api/graph/proposal-evidence` have no replacement and no caller. A Rust test now pins these five as the only Console routes the Rust daemon leaves unserved.
