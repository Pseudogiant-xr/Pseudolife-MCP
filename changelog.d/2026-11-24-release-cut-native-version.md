### Changed (2026-11-24 — batch tooling and the Python installer engine read the native release version)
- `ops/integrate.py` counts a member as a release cut, which it batches alone, when the member changes the native release version (`[package] version` in `rust/shim/Cargo.toml`) or, as before, `pyproject.toml`'s version. Each version counts only where both revisions carry it. So a pull request that deletes `pyproject.toml` with the package is not taken for a cut, and neither is an ordinary pull request or one that edits the crate without changing its version.
- `ops/installer_engine.py` reads a checkout's release version from `rust/shim/Cargo.toml` through `rust/ci/release_version.py`, and its refusals name that file. A crate file that is missing or not UTF-8 text is now refused with the step that restores it, where before it crashed. A defaulted install does not fall back to Python on that refusal.
