### Changed (2026-11-24 — batch tooling and the Python installer engine read the native release version)
- `ops/integrate.py` now counts a member as a release cut, which it batches alone, when the member changes the native release version (`[package] version` in `rust/shim/Cargo.toml`) or, as before, `pyproject.toml`'s version. The native version counts only where both revisions carry the crate. An ordinary pull request, or one that edits the crate without changing its version, is classified as before.
- `ops/installer_engine.py` reads a checkout's release version from `rust/shim/Cargo.toml` through `rust/ci/release_version.py`, and its refusal names that file. A checkout whose crate file cannot be read is refused instead of crashing, and a defaulted install does not fall back to Python on it.
