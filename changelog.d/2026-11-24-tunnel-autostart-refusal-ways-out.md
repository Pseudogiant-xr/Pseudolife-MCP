### Fixed (2026-11-24 — the tunnel autostart refusal names ways out that stay true when the native client becomes the default)
- When a machine stays on the Python client because a tunnel is registered to start by itself, the refusal now says to rerun with `PSEUDOLIFE_SHIM_ENGINE=python` to stay. Rerunning without `PSEUDOLIFE_SHIM_ENGINE=native` would move the machine once the native client is the default.
- The refusal now names the service manager's own commands for removing the autostart (`systemctl disable --now`, deleting the unit and `daemon-reload`; `launchctl bootout`, deleting the plist; or `schtasks /Delete`), which need no Python client. The Python client's `pseudolife-mcp tunnel service remove` command stays as the alternative. The note for a check that could not run names the same commands, instead of telling the user to switch back to the Python client.
- An unattended run that keeps the client no longer says a later run will move it. It names the command a person runs: `PSEUDOLIFE_SHIM_ENGINE=native pseudolife-mcp update --clients-only`.
