### Fixed (2026-11-07 — the Windows scripts find a Python reached only through the py launcher)
- `ops/install.ps1`, `ops/preflight.ps1` and `ops/update.ps1` probed the `py` launcher with `- 3` instead of `-3`: a PowerShell if-expression unrolled the one-item argument array into a string, which splatted as characters. On a host whose only Python is `py`, install refused at preflight ("Python >= 3.10 is needed"), the Claude Desktop check could pass falsely, and `ops/update.ps1` ran `py - 3 update.py`, an empty script that exited 0 without updating. All five probes now pass `-3`.
