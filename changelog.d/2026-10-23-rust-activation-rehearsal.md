### Added (2026-10-23 — rehearse activating the Rust slice and rolling it back, on disposable state)
- `rust/daemon/harness/rehearse_activation.py`, an on-demand contributor rehearsal, checks two things on disposable state only. It installs runtimes behind the real launcher and a real Claude Desktop registration and checks which runtime the registered command runs after an install, a rollback install and a removal. It also opens one disposable bank with the Python daemon, then the Rust daemon (with a restart), then the Python daemon again, and checks that every write stays readable. It refuses to start a daemon on any database it did not create, and writes its evidence with machine paths replaced by placeholders.
- The first run (Windows, master `bd8217a1`'s CI binaries) is in `evals/results/rust-activation-rehearsal-20261023/`: launcher selection and Python reading a Rust-written bank after rollback held. Two findings block a real activation: the Rust daemon reports `/health` version `0.0.0` (its crate version), so every shim's version-skew check refuses it, and the Python daemon rewrites a newer bank's `schema_version` down to its own without a warning.
