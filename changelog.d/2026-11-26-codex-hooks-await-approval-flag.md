### Fixed (2026-11-26 — hooks that await approval name the flag that approves them)
- When the native installers' Codex step finds PseudoLife's hooks present but not yet trusted, its recovery line now says to rerun the installer with `--codex-hook-trust yes` (`install.ps1`: `-CodexHookTrust yes`), which also approves the `memory_message` board tool, or to review the hooks alone in Codex `/hooks`. It used to say to rerun the installer interactively, which a rerun of a Docker install cannot do: the installers run this step non-interactively on every rerun of a Docker install and on any unattended or non-terminal run, so that rerun approved nothing. The line keeps its `PseudoLife hooks await approval.` start, which the installers' final summary matches.
