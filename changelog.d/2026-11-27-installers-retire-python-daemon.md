### Changed (2026-11-27 — the installers never install the retired Python daemon)
- The Python daemon is retired, so `ops/install.sh`, `ops/install.ps1` and their native installers no longer land a host on it. `--engine python` (Windows: `-Engine python`) is refused before anything changes. An install with no bearer to come (`--no-token`, `--transport http` with no token, or no shim tooling to mint one), or whose release has no Rust image or models, now refuses with its cause and fix instead of falling back to Python. A bank that already exists, and a host still on the Python daemon, come up as they are and are then moved to Rust through `pseudolife-mcp update`, which backs up and checks the bank first. The native client's engine step no longer suggests the Python daemon in any refusal.
