### Fixed (2026-11-08 — a Console consolidate with a list source no longer breaks stores, searches and the source list)
- The Console's consolidate stores a raw JSON `source` as given. On the Python daemon, the new entry kept the raw list in memory until a restart, so anything hashing it raised `unhashable type`: every later store into a full band (capacity eviction) answered 500, as did searches filtered by `sources=` and the source list. The live entry now holds the text PostgreSQL stored (`{user}` for `["user"]`, `true` for `true`), as it would after a restart and as the Rust daemon already does, and eviction weighs any non-string source 1.0, the weight of an unweighted tier. String sources are unchanged.
