### Changed (2026-11-24 — the Rust regression gate can establish its baseline)
- The Rust regression gate's fixture replay accepts a write the daemon keeps as its standing value. That happens for a compression echo or a value that is equal after normalisation, and `memory_fact_set` answers `confirmed` with the slot's previous value. Each such write is listed under `echo_confirmed` in `contexts.json` and the baseline candidate. Every other difference from the fixture's history still makes the run incomplete. The first authorised baseline run had stopped on four such writes (#1924).
- The gate builds its context cells several at a time (`-ContextWorkers`, sized by default to free memory, commit headroom and cores). Each daemon stays on one ORT thread, so the contexts are byte-identical to a serial build, and the first failed cell stops the others at their next turn. It also records every context before the model server starts, so the GPU is held only for answering and judging.
