### Changed (2026-11-24 — the Rust regression gate can establish its baseline)
- The Rust regression gate's fixture replay accepts a write the daemon keeps as a compression echo (`memory_fact_set` answers `confirmed` with the slot's previous value) and lists each one under `echo_confirmed` in `contexts.json` and the baseline candidate. Every other difference from the fixture's history still makes the run incomplete. The first authorised baseline run had stopped on three such writes (#1924).
- The gate builds its context cells several at a time (`-ContextWorkers`, sized by default to free memory and cores). Each daemon stays on one ORT thread, so the contexts are byte-identical to a serial build. It also records every context before the model server starts, so the GPU is held only for answering and judging.
