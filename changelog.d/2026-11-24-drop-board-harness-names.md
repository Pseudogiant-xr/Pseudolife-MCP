### Removed (2026-11-24 — the board's harness-title off switch, PSEUDOLIFE_BOARD_HARNESS_NAMES, is no longer a supported setting)
- `PSEUDOLIFE_BOARD_HARNESS_NAMES` is dropped: the configuration guide no longer documents it, the tests no longer check it, and it will not be ported. The native daemon and client never read it, and the native client reads no harness title (no Claude Code transcript, no Codex `session_index.jsonl`), so on the native client a board row is named by the agent's own name, then the session title, then its label and short id, whether or not the variable is set.
- If you set it: nothing breaks and nothing needs removing. The frozen Python shim keeps honouring it, unsupported, until that package is removed, and the variable has no effect on the native client. To give a row a name of your choosing, set it with `memory_agents(action="update", name=...)`, which outranks a harness title.
