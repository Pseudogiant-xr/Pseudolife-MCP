### Fixed (2026-11-25 — the Rust regression gate accepts the reproducible Qwen server it starts)
- The Rust eval drivers' model check accepts a llama.cpp server that names the pinned model file by its full path. The reproducible Qwen server starts with `-m <path>` and no alias, and engine b10488 then reports that path in `/v1/models` and in every chat response, whatever model the request named. So the gate refused the server it had just started, after building all 78 contexts. The check now compares the file name at the end of the reported id. Another file, or a name that only contains the pinned one, is still refused, and the error names both files, never the directory.
