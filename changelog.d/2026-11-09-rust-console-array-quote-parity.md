### Fixed (2026-11-09 — Rust daemon quotes Unicode-space list elements as psycopg 3.3.7 does)
- psycopg 3.3.7 started quoting a string list element that holds one of seventeen Unicode spaces (U+1680, U+2000–U+200A, U+2028, U+2029, U+202F, U+205F, U+3000) in the array text it binds. The Rust daemon now writes the same text, so a Console graph decision given such a list as its `id` echoes the same BIGINT error as the Python daemon, and a list of strings stored as text (a proposal `rationale`, a correction's `source`, a synced cortex row) keeps the same text. The three places that wrote this text now share one function, which also fixes the Console path leaving a vertical tab (U+000B) unquoted.
