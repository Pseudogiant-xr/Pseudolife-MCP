### Fixed (2026-11-27 — a dream rollback reverses the fact the dream actually replaced)
- A dream pass journals, for each fact it writes, what the slot held before, so `memory_dream(action="rollback")` can put it back. It read that state before its write took the daemon's write lock, so a fact forgotten or rewritten in between was journaled as the slot's previous state. A rollback then reversed the wrong state: a dreamed fact written into a just-emptied slot was left in place (`skipped:no_reversal`). The journaled state is now read by the write itself, under the lock, just before it changes the slot.
