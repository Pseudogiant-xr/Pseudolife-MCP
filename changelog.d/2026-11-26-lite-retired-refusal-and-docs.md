### Changed (2026-11-26 — the lite tier is no longer offered as a way to install)
- The README Quickstart, its translations and the install, provider and comparison guides no longer offer the lite tier (`pip install "pseudolife-mcp[lite]"`) as a way to install or run Pseudolife: they say it is retired and send a machine that still holds a lite bank to "Move a lite bank to Docker" in `docs/guide/configuration.md`. That section now says the lite tier is retired, why it uses the 0.23.x pip release (the last whose full test suite ran on a lite bank), and how to install that release into its own virtualenv when the machine does not have it. The first-update recipe for 0.15.0 and earlier no longer upgrades a lite install in place.
- The native client's refusal of a lite-tier bank (`backup`, `restore`, `export`, `import`, `invite`, `maintainer`, `lease`, `board-audit`) now says the lite tier is retired and names one next step, the move, with the guide's full web address so it can be opened without a checkout. It used to lead with "the pip release (pseudolife-mcp 0.23.x)", which read as a pip install to keep using lite; which release still opens the bank is now said once, in the guide.
