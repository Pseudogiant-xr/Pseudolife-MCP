### Changed (2026-11-07 — the Rust daemon becomes the default Docker engine)
- A new Docker install (`ops/install.sh`, `ops/install.ps1`) runs the Rust daemon unless `--engine python` / `-Engine python` says otherwise. With no `--engine`, an install that would have no bearer token, or whose release publishes no Rust image or whose models cannot be downloaded, takes the Python daemon and says why.
- An attended release-mode `pseudolife-mcp update` moves a host that never chose an engine (Python, with no accepted selection recorded) to the Rust daemon when the target release publishes its image, through the same backup, rollback tag and health gate as `--engine rust`; it stays on Python with one line when the image is missing. Unattended updates never change the engine. `update --engine python` switches back and records the choice, so later updates keep Python.
