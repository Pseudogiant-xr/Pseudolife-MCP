- `ops/integrate.py`'s `RUST_HARNESS`, the Python tests under `rust/` that a batch runs locally because the full suite never collects them, now lists every pytest path of `rust.yml`'s `rust` job. With it, a harness database case that finds no bench login or no Docker engine fails, naming the cause and the fix, instead of skipping, so a skipped database case cannot pass the batch unseen.
