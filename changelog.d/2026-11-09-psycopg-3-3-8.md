### Changed (2026-11-09 — the Python daemon quotes list elements the way current psycopg does)
- `psycopg[binary]` 3.3.7 is now the minimum, and the daemon image installs 3.3.8 (from 3.3.4). psycopg 3.3.7 started double-quoting list elements that contain one of 17 Unicode space characters (U+1680, U+2000 to U+200A, U+2028, U+2029, U+202F, U+205F, U+3000) when it binds a Python list as array text. The Rust daemon now quotes the same set, so the floor keeps both daemons writing and echoing the same list text whatever psycopg an install resolves.
