### Changed (2026-11-09 — the Python daemon quotes list elements the way current psycopg does)
- `psycopg[binary]` 3.3.8 is now the minimum (from 3.2.4), and the daemon image installs it (from 3.3.4). psycopg 3.3.7 started double-quoting list elements that contain one of 17 Unicode space characters (U+1680, U+2000 to U+200A, U+2028, U+2029, U+202F, U+205F, U+3000) when it binds a Python list as array text. The Rust daemon quotes the same set (landing alongside this change), so the floor keeps both daemons writing and echoing the same list text whatever psycopg an install resolves. 3.3.8 rather than 3.3.7 because 3.3.8 reverted 3.3.7's `/etc/ssl` setting in its Linux and macOS wheels.
