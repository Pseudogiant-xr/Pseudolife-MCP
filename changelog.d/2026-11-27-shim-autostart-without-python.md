### Fixed (2026-11-27 — the shim autostart scripts work on a machine without Python)
- `ops/install-shim-autostart.sh` / `.ps1` and `ops/install-codex-shim-autostart.sh` / `.ps1` refused on a machine with no Python unless `--native` / `-NativeExe` named the native client, and told the user to install Python. They now find the native client where the installers put it (or `PSEUDOLIFE_SHIM_LAUNCHER`) and register the shim through it, as the installers do; `--python` / `-PythonExe` still picks the Python runner. When neither is available, the refusal names the native install. Without systemd, the `.sh` scripts now print the native `pseudolife-mcp extractor-shim` command to run by hand, and a host without a `docker0` bridge no longer stops them before they register anything. The guides no longer tell users to run the Python shims, and `ops/update.sh` / `ops/update.ps1` name `pseudolife-mcp update --clients-only` for updating the clients alone.
