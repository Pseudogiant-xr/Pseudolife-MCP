### Added (2026-11-07 — release-mode update can select the Rust daemon)
- `pseudolife-mcp update --engine rust` now works in release mode on a Docker host, for a release that publishes the `ghcr.io/pseudogiant-xr/pseudolife-daemon-rust:<version>` image. It keeps the bank, `/data` volume, port and bearer settings: it refuses a bank whose counters were never imported, pulls and probes the image, installs the pinned models into `/data/models` while the running daemon keeps serving, backs up, tags the running image for rollback, recreates only the daemon, and records the selection only after the new daemon passes its version, schema and authenticated-read check. If the release has no Rust image, the pull fails and nothing changes.
- On a Rust host, `update` without `--engine` keeps Rust; `update --engine python` switches back to the Python daemon on the same bank. Python remains the default for every host that has not chosen.
- The package bundles `docker-compose.rust-ghcr.yml` beside its other Compose files, so a release update whose compose files are gone can still select Rust.
