### Added (2026-11-07 — release-mode update imports legacy counters before switching to Rust)
- `pseudolife-mcp update --engine rust` on a Python host whose bank still keeps its CMS counters in `memory_state/weights.pt`, or is below schema v57, no longer refuses: it first updates to the Python daemon at the target release, whose startup imports the counters into `cms_counters`, then switches to the Rust daemon. Each step is its own backup, rollback tag and health gate, in both the Python and native updaters. If the Python daemon did not import them, the update stops there, on Python, and says to check its log. Checkout-mode `update --engine rust --checkout` still refuses such a bank, naming the same fix.
