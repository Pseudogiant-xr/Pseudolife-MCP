### Fixed (2026-11-27 — old native runtimes are cleaned up on ordinary Linux and macOS machines)
- After an update, the native client removes the runtimes it no longer uses. On Linux it gave up whenever one of the account's own processes hid its executable path, as ssh-agent, gpg-agent and browser sandboxes do. On macOS it gave up whenever `ps` named a process without a full path, which it does for programs started from a shell, system daemons and zombies. Old runtimes therefore piled up under the runtimes folder. Such a process now counts as running without a known path, as on Windows, and the runtime's usage lock decides whether a runtime is still in use, so only unused runtimes are removed.
