### Changed (2026-11-27 — the Portainer/Dockge/Komodo stack file runs the Rust daemon)
- `ops/docker-compose.stack.yml` deployed the retired Python daemon (`pseudolife-daemon:latest`). It now runs the Rust daemon, `ghcr.io/pseudogiant-xr/pseudolife-daemon-rust`, defaulting to this release's version because that image is published per release only, with the engine label, `PSEUDOLIFE_DAEMON_MODELS_DIR=/models` and the `pseudolife_rust_models` volume that `pseudolife-mcp update` uses, so the models download once on first start and stay out of backups. The stack file's default tag becomes part of the version cut. `pseudolife-mcp update` now adopts such a stack-deployed Rust daemon, which carries the engine label alone, and records its activation; it used to refuse it as an unfinished activation. An existing stack still on the Python daemon moves with `pseudolife-mcp update`, which backs up and checks the bank first; the guide says not to move it by redeploying the new file.
