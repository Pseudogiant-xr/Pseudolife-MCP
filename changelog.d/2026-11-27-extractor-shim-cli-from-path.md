### Changed (2026-11-27 — the extractor shim runs the `claude` or `codex` on your PATH, not one in the working folder)
- `pseudolife-mcp extractor-shim` (and its `install-autostart`) now looks a bare `--cli claude` or `--cli codex` (the default) up only in `PATH`'s absolute directories, the same rule SECURITY.md promises for `pg_dump` and `tailscale`. Before, a file of that name in the working folder, the `--repo` checkout or the settings file's folder was tried first, so a checkout could carry its own `claude`. A path you pass yourself (`--cli ./claude`, `--cli /opt/claude/bin/claude`) works as before, and Windows still finds the newest Codex in its install folder.
- On Linux and macOS a file that is not executable is no longer taken for the CLI, and the error for a missing CLI says where it was looked for and how to point at it.
