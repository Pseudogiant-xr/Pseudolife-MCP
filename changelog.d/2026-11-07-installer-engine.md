### Added (2026-11-07 — the Docker installers can install the Rust daemon)
- `ops/install.sh --engine rust` and `ops/install.ps1 -Engine rust` install the Rust daemon from the image the checkout's release publishes. They check free disk space, pull the image and provision its pinned models into the `pseudolife_rust_models` volume before any container starts, so a missing image or a failed download refuses with nothing started and names `--engine python`. The selection is recorded only once the daemon reports ready at that release with no counters left to import, in the same form `pseudolife-mcp update` verifies, so later updates keep Rust. Rust needs a bearer, since update verifies a Rust daemon with an authenticated read: `--no-token`, or `--transport http` with no token in `ops/.env` or the environment, refuses `--engine rust`, and a Rust daemon that still came up without one is not recorded.
- A rerun keeps the engine installed, with no flag needed, also after `docker compose down`. Before, the installer's Compose step and its change check used only the base Compose file, so a rerun on a host that `update --engine rust` had switched would recreate the daemon from it. Naming the other engine on an existing install, or `--engine rust` for a bank that already exists, finishes the install on the current engine and then switches through `pseudolife-mcp update --engine`, with its backup, rollback tag, health gate and closed stdin. A Rust daemon whose selection was never accepted is redone only for this checkout's release; another release refuses, naming the fix. A Rust daemon selected by checkout-mode update is left to `update --checkout`: the installer refuses rather than rebuild it without a backup. A refused Rust install creates no volume, so the rerun its message suggests is not blocked. A new install without the flag still gets the Python daemon, and a client-only install refuses `--engine`, also when client-only is implied by `--daemon-url`.
- On a Rust daemon, the installer's extractor reachability checks run `curl` inside the container instead of Python, which the Rust image lacks.
