# Every tests/test_*.py file, classified (tests/suite_classes.py says how).
# live: collected by default. frozen: exercises only the frozen pseudolife_memory
#   package (frozen since 14 November 2026); collected only with --include-frozen.
#
# A test file is live when any of these holds; frozen only when none does
# (tests/test_suite_classes.py checks the lexical part):
# 1. It tests something that still changes or ships: a quoted ops/, plugin/,
#    .github/, docs/, .claude/, examples/, frontend/, rust/ or evals/ path (or
#    such a join), README, CLAUDE.md, CHANGELOG, llms*.txt, server.json,
#    pyproject.toml, Dockerfile or compose file; an import of evals or ops.
# 2. It tests the suite's own infrastructure: tests/conftest.py,
#    tests/fake_embedder.py, tests/pg_fixtures.py (its private members),
#    tests/pg_defaults.py, tests/report_redaction.py, the suite profiler,
#    tests/suite_lock.py, tests/client_environment.py; or it imports a helper
#    from a live test module that does any of 1-2.
# 3. It imports a pseudolife_memory module that an open, maintainer-ruled
#    freeze exception changes. Re-freeze these once the exception has landed
#    (a test of a landed exception change is frozen again):
#    - #1539, the expose security fix (backup_cli, client_updates,
#      codex_connection, codex_doorbell, expose_cli, maintainer_setup,
#      program_lookup, runtimes, tunnel_runtime, update_cli):
#      test_backup_cli.py, test_child_python.py, test_codex_cli_connection.py,
#      test_codex_doorbell.py, test_codex_doorbell_revision.py,

#      tree, through helpers of live test modules), test_coordination_adapter.py,
#      test_coordination_integration.py, test_docker_backup_restore.py,

#      test_reference_bank.py, test_tunnel_bridge.py, test_tunnel_runtime.py,
#      test_tunnel_service.py, and test_invite_cli.py (invite_cli drives
#      expose_cli).
#    - #1537 and #1539 both (update_cli, and #1537's update_bridge):
#      test_disk_space.py, test_update_backup_connection.py,
#      test_update_client_handoff.py.
#    #1539 adds test_program_lookup.py and #1537 test_update_bridge.py, each
#    with its own live line.
# 4. The maintainer's conductor ruled it live (14 November 2026), each until
#    the event named:
#    - test_embedded_pg.py: CI's own PostgreSQL launcher on the Windows lanes;
#      frozen once those lanes start PostgreSQL another way.
#    - test_lease_cli_board.py, test_repository_claims.py (with

#      through the Python `lease check`; frozen once they use the native one.

#      conductor watcher; frozen once it is ported.
#    - Kept live from the start: the update CLI path the last release's

#      node id (test_cli_dispatch.py, test_rust_mcp_catalogue.py,

# or deletes it, by these rules.
